# LeftoverRescue – Frontend Demo

A responsive, frontend-only prototype inspired by the LeftoverRescue assignment.

## Files
- `index.html` – page structure and content
- `style.css` – responsive styling
- `script.js` – demo interactions and sample data

## Run locally
Open `index.html` in a browser. No installation or backend is required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `leftoverrescue`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Demo limitations
This is a static frontend prototype. Login is not authenticated, reservations are simulated in browser memory, and no real payment, database, notification service, or restaurant backend is connected. Data resets when the page is refreshed.
